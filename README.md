# Paipai · Annie图文排版
> ✨ 文艺清新风图文拼贴海报排版工具，浏览器本地运行，所有图片不会上传服务器。
> 
## 📖 项目介绍
Paipai‑Annie‑Layout 是一款**纯前端本地图文排版工具**，专为创作爱好者设计。
浅雾霾蓝文艺视觉风格，支持图片拖拽上传、自由摆放卡片错位堆叠、自定义文字样式，在浏览器内完成海报创作，一键导出PNG图片。
全部操作在本地浏览器完成，照片仅保存在你的设备，不会上传至任何服务器，保护图片隐私。

适合制作：谷美卡片、作品集插图、手账拼贴、社交平台海报、氛围感图文。

## 🎨 视觉风格
- 底色：浅雾霾蓝，温柔低饱和色调
- 装饰元素：细碎圆点、小方块、手绘线稿蝴蝶、蓝玫瑰、海面简约装饰
- 卡片效果：错位堆叠布局，柔和阴影，层次感拼贴效果
- 大量留白，安静文艺，简约不花哨

## 🚀 核心功能
- ✅ 点击 / 拖拽导入本地图片到画布
- ✅ 添加自定义文字，调节字体、字号、字体颜色、对齐方式
- ✅ 图片、文字组件自由拖动，支持多层错位堆叠排版
- ✅ 自定义画布背景色
- ✅ 一键导出画布内容为 PNG 图片下载
- ✅ **全部运算本地浏览器完成，图片不上传网络，保护隐私**
- ✅ 纯静态页面，无后端，可部署到任意静态托管平台

## 📦 本地运行
将整套项目源码下载保存到本地电脑
直接双击打开 index.html 文件，就会在浏览器打开工具页面
无需安装软件、无需搭建服务器，打开即可全部使用
⚠️ 注意：不要直接在 VS Code 的预览插件中使用导出功能，导出图片功能请使用 Chrome / Edge 浏览器打开。

## 📌 使用说明
导入图片：点击页面右上角【导入图片】按钮，或者直接将图片拖拽到画布区域
添加与编辑文字：在左侧控制面板输入文字内容，调整字体、字号、颜色、对齐方式
自由排版：鼠标拖拽画布上的图片块、文字块，可以自由移动位置，实现错位堆叠拼贴效果
设置画布：左侧面板修改画布背景颜色，调整画面效果
导出作品：排版完成后，点击右上角【导出图片】按钮，即可将画布内容下载为 PNG 图片保存到电脑。
