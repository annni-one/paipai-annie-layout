# Paipai · Annie 图文拼贴排版

> ✨ 文艺清新风图文拼贴海报排版工具，浏览器本地运行，所有图片不上传服务器。

浅雾霾蓝文艺视觉风格，支持图片拖拽上传、自由摆放卡片错位堆叠、自定义文字样式，在浏览器内完成海报创作，一键导出 PNG 图片。
全部操作在本地浏览器完成，照片仅保存在你的设备，不会上传至任何服务器，保护图片隐私。

适合制作：谷美卡片、作品集插图、手账拼贴、社交平台海报、氛围感图文。

## 🖌 视觉风格

- **底色**：浅雾霾蓝，温柔低饱和色调
- **装饰元素**：细碎圆点、小方块、手绘线稿蝴蝶、蓝玫瑰、海面简约装饰
- **卡片效果**：错位堆叠布局，柔和阴影，层次感拼贴
- **留白**：大量留白，安静文艺，简约不花哨

---

## 🚀 核心功能

- ✅ 点击 / 拖拽导入本地图片到画布
- ✅ 4 种拼贴风格一键切换，自动按图片数量推荐
- ✅ 多比例画布：3:4、4:5、1:1、9:16、16:9、4:3，支持自定义尺寸
- ✅ 8 种情绪氛围：欢快、忧郁、平静、浪漫、怀旧、大胆、梦幻、疏离
- ✅ 添加自定义文字，调节字体、字号、颜色、对齐方式
- ✅ 图片、文字组件自由拖动，支持多层错位堆叠排版
- ✅ 自定义画布背景色，可重置为自动取色
- ✅ 一键导出画布内容为 PNG 图片下载
- ✅ 全部运算本地浏览器完成，图片不上传网络，保护隐私
- ✅ 纯静态页面，无后端，可部署到任意静态托管平台

## 📌 使用说明

1. **导入图片**：点击页面左侧上传区，或直接将图片拖拽到画布区域
2. **选择风格**：左侧「风格」面板点击切换 4 种拼贴排版
3. **调整画布**：右侧选择尺寸比例、情绪氛围，输入想放进画面的文字
4. **自由排版**：鼠标拖拽画布上的图片块、文字块，可单独移动位置，实现错位堆叠拼贴效果
5. **设置背景**：右侧面板修改画布背景颜色，或点「自动」由 AI 取色
6. **导出作品**：排版完成后，点击「生成 4 张布局」即可预览并下载 PNG 图片

本工具为纯前端静态页面，所有图片分析、配色提取、排版渲染均在你的浏览器内完成，**不会上传任何图片到服务器**。你可以直接把 `index.html` 和配套目录部署到 GitHub Pages、Cloudflare Pages、Vercel 等任意静态托管平台。
